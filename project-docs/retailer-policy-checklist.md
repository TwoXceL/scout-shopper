# Retailer Policy Collection Checklist (US + Canada first)

Compiled from general knowledge: confirm each retailer exists and operates as described in your market.
Status: **V** = verified from the retailer's page, **-** = need from you.

## What to send for each retailer (screenshots of the live page are fine)
1. **Price match / low price guarantee** page (competitors matched? own-price only? online vs in-store? marketplace exclusions? time window?)
2. **Price adjustment** policy (post-purchase price drop, number of days, receipt/proof rules)
3. **Exclusions** (clearance, open box, refurbished, bundles, coupons, special sale events, limited quantity)
4. **Holiday / seasonal** price match changes
5. **Affiliate program** page (network, commission rates, cookie length, prohibited methods, e.g. coupon/toolbar rules)
6. **Terms of use / API / data feed** (is automated price lookup allowed? is there an official product API or feed?)

## Priority 3 - Small and independent (different rules)
- **Etsy:** Affiliate program and API terms; seller policies vary per shop
- **Shopify stores:** No central policy. Need Shopify storefront data terms plus each brand's own price/return policy (merchant-submitted in the portal)
- **Affiliate networks:** Impact, CJ, Rakuten Advertising, ShareASale (Awin), Refersion, UpPromote: terms for app/coupon-style use
- **Marketplaces:** eBay (Partner Network), Facebook Marketplace (probably out of scope)

## Platform and legal pages (not retailers, but also needed)
- Apple App Store Review Guidelines (shopping, affiliate links, tracking/ATT, privacy labels)
- Google Play Developer Policy (Data Safety, ads, affiliate disclosure)
- Google AdMob / UMP consent requirements; Amazon Associates Operating Agreement (strict on price display and caching)
- Retailer API terms that restrict showing prices without refresh (Amazon PA-API, Walmart, eBay)

## Suggested order
1. Walmart (US), Best Buy (US), Home Depot, Amazon (US), Costco: finishes the US electronics/home MVP.
2. Walmart Canada, Amazon.ca, Canadian Tire, Costco Canada, Home Depot Canada: finishes Canada.
3. Affiliate and API terms for the above: these decide whether live prices are even allowed.
